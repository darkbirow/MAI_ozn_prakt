## Описание программы

Программа обрабатывает данные о самолётах, совершивших посадку, и сортирует их по возрастанию количества пассажиров. Используется **индексная сортировка линейным методом** (метод выбора): сами записи в памяти не перемещаются, переставляются только элементы вспомогательного массива индексов.

Дополнительно программа подсчитывает суммарное количество пассажиров и суммарный вес грузов.

Данные о самолётах хранятся в текстовом файле:
- каждая строка — запись об одном ЛА;
- выполняется входной контроль бортового номера, количества пассажиров и веса груза; строки с ошибками выводятся в списке ошибок и в таблицу не попадают.

Структура записи:

```
Марка_ЛА  Бортовой_номер  Количество_пассажиров  Груз
ТУ-154М   Б-9876          145                    28.5
```

Правила входного контроля:
- **Бортовой номер** — формат `Б-хххх`, где `хххх` — ровно 4 цифры;
- **Количество пассажиров** — целое число от 0 до 999, только цифры;
- **Груз** — число от 0 до 200 т, разделитель — точка, не более 2 знаков после точки;
- в строке должно быть ровно 4 параметра;
- один и тот же бортовой номер не может принадлежать разным маркам ЛА.

## Компиляция и запуск

```
g++ main.cpp -o main -static
./main
```

На Windows (cmd) запуск: `main.exe`. Тестовые файлы должны лежать в той же папке, из которой запускается программа.

После запуска программа выводит список тестовых файлов и просит ввести номер файла (1–20).

## Тестовые файлы

- `test1.txt` основной тестовый набор с корректными данными.
- `test2.txt` единственная запись.
- `test3.txt` граничные значения: 0 и 999 пассажиров, груз 0, 0.01 и 200.
- `test4.txt` несколько ЛА с одинаковым количеством пассажиров.
- `test5.txt` длинные названия марок ЛА для проверки ровности таблицы.
- `test6.txt` данные, уже отсортированные по возрастанию.
- `test7.txt` данные в обратном порядке.
- `test8.txt` корректные данные с лишними пробелами и табуляциями.
- `test9.txt` груз без дробной части и с двумя знаками, ведущие нули.
- `test10.txt` большой объём данных (50 записей) без ошибок.
- `test11.txt` некорректное количество пассажиров (больше 999, дробное).
- `test12.txt` некорректный вес груза (запятая, 3 знака, `.5`, `12.`, две точки).
- `test13.txt` буквы вместо цифр.
- `test14.txt` лишние слова и комментарии в строке.
- `test15.txt` нехватка параметров в строке.
- `test16.txt` некорректный формат бортового номера.
- `test17.txt` отрицательные значения и выход за допустимый диапазон.
- `test18.txt` один БН указан для разных марок ЛА.
- `test19.txt` пустой файл для проверки устойчивости программы.
- `test20.txt` мусор, пустые строки и символы вместе с данными.
